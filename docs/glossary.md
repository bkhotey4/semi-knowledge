# 術語表

收錄各章「本章術語」，依字母與筆畫排序，點章節可回到原文。

| 術語 | 說明 | 出處 |
|---|---|---|
| **Bloch's Theorem** | （布洛赫定理）：描述在週期性晶格勢場中運動的電子波函數，可表述為自由平面波與具晶格週期性函數之乘積的量子力學定理。 | [第 1 章](part-01/01-01.md) |
| **Conduction Band, CB** | （導電帶 / 導帶）：位於價電帶上方之第一個未填滿（或完全為空）的能帶，其內部電子可自由移動形成電流。 | [第 1 章](part-01/01-01.md) |
| **Crystal Momentum** | （晶體動量）：由約化普朗克常數與波向量乘積（$\mathbf{p}_{\text{crystal}} = \hbar \mathbf{k}$）定義之有效動量，在週期性勢場交互作用下遵循守恆律。 | [第 1 章](part-01/01-01.md) |
| **Density of States, DOS** | （狀態密度）：單位能量區間與單位晶體體積內，允許電子佔據的微觀量子態數量。 | [第 1 章](part-01/01-01.md) |
| **Diamond Structure** | （鑽石結構）：由兩個面心立方（FCC）晶格沿對角線位移四分之一晶胞長度相互套構而成的晶體結構，為矽與鍺的標準晶體型態。 | [第 1 章](part-01/01-01.md) |
| **Direct Bandgap** | （直接能隙）：導電帶能量最低點與價電帶能量最高點座落於第一布里淵區相同波向量（通常在 $\Gamma$ 點）的能帶結構。 | [第 1 章](part-01/01-01.md) |
| **Effective Density of States, $N_c, N_v$** | （有效狀態密度）：將連續分佈的能帶態密度等效積分至導帶底或價帶頂的特徵常數，隨溫度呈 $T^{3/2}$ 關係增長。 | [第 1 章](part-01/01-01.md) |
| **Fermi Level, $E_F$** | （費米能階）：電子系統在熱力學平衡時的化學勢，代表特定能階被電子佔據之機率恰為 $50\%$ 的參考能量基準。 | [第 1 章](part-01/01-01.md) |
| **First Brillouin Zone** | （第一布里淵區）：動量空間（倒易空間）中以倒易點陣原點為中心所劃分的魏格納-賽茲原胞，包含晶體電子的所有非簡併量子態。 | [第 1 章](part-01/01-01.md) |
| **Forbidden Band / Energy Bandgap, $E_g$** | （禁帶 / 能隙）：導電帶底與價電帶頂之間的能量間隔，在此能量範圍內理想晶體不存在任何容許電子佔據的量子態。 | [第 1 章](part-01/01-01.md) |
| **Indirect Bandgap** | （間接能隙）：導電帶能量最低點與價電帶能量最高點在動量空間中波向量不一致的能帶結構。 | [第 1 章](part-01/01-01.md) |
| **Intrinsic Carrier Concentration, $n_i$** | （本質載子濃度）：本質半導體在熱平衡狀態下的自由電子濃度或電洞濃度，兩者在數值上嚴格相等。 | [第 1 章](part-01/01-01.md) |
| **Intrinsic Semiconductor** | （本質半導體）：未經人工雜質原子摻雜、載子完全由共價鍵斷裂熱激發生成的超高純度半導體。 | [第 1 章](part-01/01-01.md) |
| **Phonon** | （聲子）：固體物理中晶格熱振動集體激發的能量量子，具備微小能量與可在布里淵區中提供廣泛動量的準粒子。 | [第 1 章](part-01/01-01.md) |
| **Thermal Runaway** | （熱失控）：半導體元件因溫度升高促使本質載子與漏電流呈指數暴增，耗散功率轉化為熱能進一步推升溫度，最終導致元件燒毀的惡性正回授機制。 | [第 1 章](part-01/01-01.md) |
| **Valence Band, VB** | （價電帶 / 價帶）：在絕對零度且無外加激發能量下，由價電子所填滿的最高能量容許帶。 | [第 1 章](part-01/01-01.md) |
| **Varshni Empirical Equation** | （Varshni 經驗方程式）：定量描述半導體能隙寬度隨溫度升高而呈現非線性收縮規律的經驗模型。 | [第 1 章](part-01/01-01.md) |
| **Wide Bandgap Semiconductor, WBG** | （寬能隙半導體）：能隙顯著大於傳統矽材料（通常 $E_g > 3.0\text{ eV}$）的半導體材料，代表性材料包括碳化矽（SiC）與氮化鎵（GaN）。 | [第 1 章](part-01/01-01.md) |
