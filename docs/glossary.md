# 術語表

收錄各章「本章術語」，依字母與筆畫排序，點章節可回到原文。

| 術語 | 說明 | 出處 |
|---|---|---|
| **$N_C, N_V$** | （導帶與價帶有效態密度，Effective Density of States）：在波茲曼近似下，將連續能帶的量子態總合等效壓縮至能帶邊界的虛擬態密度。 | [第 2 章](part-01/01-02.md) |
| **Acceptor** | （受體）：具有 3 個價電子之週期表第 III 族元素雜質，游離時接受價帶電子以產生自由電洞，並留下帶負電的固定離子。 | [第 2 章](part-01/01-02.md) |
| **APC** | （進階製程控制）：利用 EWMA 等數學模型，在批次間（R2R）動態調整機台配方以補償變異之控制系統。 | [第 54 章](part-09/09-12.md) |
| **BGN** | （能隙變窄效應，Bandgap Narrowing）：重度摻雜下載子間庫侖屏蔽及交換交互作用促使材料有效禁帶寬度縮小的現象。 | [第 2 章](part-01/01-02.md) |
| **Bloch's Theorem** | （布洛赫定理）：描述在週期性晶格勢場中運動的電子波函數，可表述為自由平面波與具晶格週期性函數之乘積的量子力學定理。 | [第 1 章](part-01/01-01.md) |
| **Carrier Freeze-out** | （載子凍結）：在極低溫環境下載子動能低於游離能，絕大部分載子被束縛於雜質原子能階而使自由載子濃度急遽衰減的現象。 | [第 2 章](part-01/01-02.md) |
| **Carrier Mobility** | （載子遷移率，$\mu$）：表徵微觀載子在單位外加電場加速作用下所能獲得的定向漂移速度比例常數。 | [第 2 章](part-01/01-02.md) |
| **Charge Neutrality Condition** | （電荷中性條件）：在宏觀體積尺度下，半導體內部自由載子與游離帶電離子的代數和為零之物理平衡狀態。 | [第 2 章](part-01/01-02.md) |
| **Conduction Band, CB** | （導電帶 / 導帶）：位於價電帶上方之第一個未填滿（或完全為空）的能帶，其內部電子可自由移動形成電流。 | [第 1 章](part-01/01-01.md) |
| **Continuity Equation** | （連續方程式）：基於電荷守恆定律，完整描述半導體內部載子濃度因傳輸梯度、產生率與復合率動態演變的微分方程。 | [第 2 章](part-01/01-02.md) |
| **Crystal Momentum** | （晶體動量）：由約化普朗克常數與波向量乘積（$\mathbf{p}_{\text{crystal}} = \hbar \mathbf{k}$）定義之有效動量，在週期性勢場交互作用下遵循守恆律。 | [第 1 章](part-01/01-01.md) |
| **Degenerate Semiconductor** | （簡併半導體）：摻雜濃度極高以致費米能階進入導帶或價帶內部，導致波茲曼近似失效且展現類金屬特徵的半導體。 | [第 2 章](part-01/01-02.md) |
| **Density of States, DOS** | （狀態密度）：單位能量區間與單位晶體體積內，允許電子佔據的微觀量子態數量。 | [第 1 章](part-01/01-01.md) |
| **Diamond Structure** | （鑽石結構）：由兩個面心立方（FCC）晶格沿對角線位移四分之一晶胞長度相互套構而成的晶體結構，為矽與鍺的標準晶體型態。 | [第 1 章](part-01/01-01.md) |
| **Diffusion Current** | （擴散電流）：載子純因濃度空間分佈不均，透過微觀隨機熱運動產生巨觀淨定向流動所形成的電流。 | [第 2 章](part-01/01-02.md) |
| **Direct Bandgap** | （直接能隙）：導電帶能量最低點與價電帶能量最高點座落於第一布里淵區相同波向量（通常在 $\Gamma$ 點）的能帶結構。 | [第 1 章](part-01/01-01.md) |
| **Donor** | （施體）：具有 5 個價電子之週期表第 V 族元素雜質，游離後提供自由導電電子並在晶格中留下帶正電的固定離子。 | [第 2 章](part-01/01-02.md) |
| **DOS** | （能態密度，Density of States）：單位體積內、單位能量區間所允許存在的電子或量子態數目。 | [第 2 章](part-01/01-02.md) |
| **EAP** | （設備自動化程式）：介於 MES 與實體機台間的中介軟體，負責指令轉譯、配方下載與自動化邏輯交握。 | [第 54 章](part-09/09-12.md) |
| **Effective Density of States, $N_c, N_v$** | （有效狀態密度）：將連續分佈的能帶態密度等效積分至導帶底或價帶頂的特徵常數，隨溫度呈 $T^{3/2}$ 關係增長。 | [第 1 章](part-01/01-01.md) |
| **Effective Mass** | （有效質量）：將晶體週期性位能對電子的量子力學交互作用等效簡化為自由粒子的慣性質量參數。 | [第 2 章](part-01/01-02.md) |
| **Einstein Relation** | （愛因斯坦關係式）：揭示熱平衡態下，載子擴散係數與遷移率之比值恆等於熱電壓（$D/\mu = k_B T / q$）的熱力學關係。 | [第 2 章](part-01/01-02.md) |
| **EtherCAT** | （乙太網控制自動化技術）：具備飛越處理與極低時間抖動特性的確定性工業乙太網路協定。 | [第 54 章](part-09/09-12.md) |
| **FDC** | （故障偵測與分類）：透過高頻感測器波形特徵分析，即時監控機台健康狀態並攔截異常之系統。 | [第 54 章](part-09/09-12.md) |
| **Fermi Level, $E_F$** | （費米能階）：電子系統在熱力學平衡時的化學勢，代表特定能階被電子佔據之機率恰為 $50\%$ 的參考能量基準。 | [第 1 章](part-01/01-01.md) |
| **First Brillouin Zone** | （第一布里淵區）：動量空間（倒易空間）中以倒易點陣原點為中心所劃分的魏格納-賽茲原胞，包含晶體電子的所有非簡併量子態。 | [第 1 章](part-01/01-01.md) |
| **Forbidden Band / Energy Bandgap, $E_g$** | （禁帶 / 能隙）：導電帶底與價電帶頂之間的能量間隔，在此能量範圍內理想晶體不存在任何容許電子佔據的量子態。 | [第 1 章](part-01/01-01.md) |
| **HSMS** | （高速 SECS 訊息服務）：SEMI E37 標準，定義於 TCP/IP 網路上傳輸 SECS-II 訊息之二進位傳輸協定。 | [第 54 章](part-09/09-12.md) |
| **Indirect Bandgap** | （間接能隙）：導電帶能量最低點與價電帶能量最高點在動量空間中波向量不一致的能帶結構。 | [第 1 章](part-01/01-01.md) |
| **Interface A / EDA** | （設備資料擷取）：SEMI 制定之高頻、唯讀、基於 Web Services 與中繼資料模型之資料擷取架構。 | [第 54 章](part-09/09-12.md) |
| **Intrinsic Carrier Concentration** | （本徵載子濃度，$n_i$）：在無雜質且無晶格缺陷之純淨半導體中，純因價帶熱激發產生的平衡電子或電洞濃度。 | [第 2 章](part-01/01-02.md) |
| **Intrinsic Carrier Concentration, $n_i$** | （本質載子濃度）：本質半導體在熱平衡狀態下的自由電子濃度或電洞濃度，兩者在數值上嚴格相等。 | [第 1 章](part-01/01-01.md) |
| **Intrinsic Semiconductor** | （本質半導體）：未經人工雜質原子摻雜、載子完全由共價鍵斷裂熱激發生成的超高純度半導體。 | [第 1 章](part-01/01-01.md) |
| **IPC** | （工業電腦）：搭載即時作業系統（RTOS）的機台底層硬體，負責微秒級閉迴路控制與安全互鎖。 | [第 54 章](part-09/09-12.md) |
| **Mass-Action Law** | （質量作用定律）：在熱力學平衡條件下，非簡併半導體中電子與電洞濃度乘積恆等於本徵載子濃度平方（$np = n_i^2$）的物理規律。 | [第 2 章](part-01/01-02.md) |
| **Matthiessen's Rule** | （馬西森定則）：當存在多種相互獨立的散射機制時，材料之總散射率等於各微觀散射率之和，總遷移率倒數等於各分支遷移率倒數之和。 | [第 2 章](part-01/01-02.md) |
| **Maxwell-Boltzmann Approximation** | （馬克士威–波茲曼近似）：當費米能階遠離能帶邊緣至少 $3k_B T$ 時，費米–狄拉克分佈所簡化成的純指數衰減統計形式。 | [第 2 章](part-01/01-02.md) |
| **MSPC** | （多變量統計製程監控）：運用 PCA 等降維技術，結合 $T^2$ 與 $Q$ 統計量同時監控數百個感測器耦合關係之方法。 | [第 54 章](part-09/09-12.md) |
| **Phonon** | （聲子）：固體物理中晶格熱振動集體激發的能量量子，具備微小能量與可在布里淵區中提供廣泛動量的準粒子。 | [第 1 章](part-01/01-01.md) |
| **Purdue Model** | （普渡模型）：將工業自動化與 OT/IT 網路劃分為不同安全層級之標準防護架構。 | [第 54 章](part-09/09-12.md) |
| **SECS/GEM** | （半導體設備通訊標準/通用設備模型）：SEMI 制定之半導體機台與廠級主機間的標準通訊與狀態機規範。 | [第 54 章](part-09/09-12.md) |
| **SPC** | （統計製程管制）：運用 Shewhart 管制圖與 Nelson Rules 對產品實體品質參數進行統計監控之技術。 | [第 54 章](part-09/09-12.md) |
| **Substitutional Doping** | （取代型摻雜）：雜質原子置換單晶矽晶格節點並形成共價鍵，從而提供電性自由載子的摻雜機制。 | [第 2 章](part-01/01-02.md) |
| **Thermal Runaway** | （熱失控）：半導體元件因溫度升高促使本質載子與漏電流呈指數暴增，耗散功率轉化為熱能進一步推升溫度，最終導致元件燒毀的惡性正回授機制。 | [第 1 章](part-01/01-01.md) |
| **Valence Band, VB** | （價電帶 / 價帶）：在絕對零度且無外加激發能量下，由價電子所填滿的最高能量容許帶。 | [第 1 章](part-01/01-01.md) |
| **Varshni Empirical Equation** | （Varshni 經驗方程式）：定量描述半導體能隙寬度隨溫度升高而呈現非線性收縮規律的經驗模型。 | [第 1 章](part-01/01-01.md) |
| **Velocity Saturation** | （速度飽和）：在強電場作用下，載子因劇烈激發高能光學聲子散射而使漂移速度趨於極限常數（$v_{\text{sat}}$）的非線性現象。 | [第 2 章](part-01/01-02.md) |
| **VM** | （虛擬量測）：利用機台加工感測數據，透過演算法即時預測晶圓實體物理品質之技術。 | [第 54 章](part-09/09-12.md) |
| **Wide Bandgap Semiconductor, WBG** | （寬能隙半導體）：能隙顯著大於傳統矽材料（通常 $E_g > 3.0\text{ eV}$）的半導體材料，代表性材料包括碳化矽（SiC）與氮化鎵（GaN）。 | [第 1 章](part-01/01-01.md) |
