| **Acceptor** | （受體）：具有 3 個價電子之週期表第 III 族元素雜質，游離時接受價帶電子以產生自由電洞，並留下帶負電的固定離子。 | [第 2 章](part-01/01-02.md) |
| **Aerodynamic Equivalent Diameter** | （空氣動力學等效直徑）：在重力場靜止空氣中終端沉降速度與不規則微粒相同，且密度為標準水密度之標準球體直徑。 | [第 55 章](part-13/13-01.md) |
| **Airborne Molecular Contamination** | （氣狀分子污染物，AMC）：以氣態分子形式存在於環境空氣中，能沉積於晶圓或光學鏡面並引發物理或化學缺陷的微量污染物質。 | [第 55 章](part-13/13-01.md) |
| **AMC** | （氣態分子污染物）：潔淨室環境中會透過物理或化學吸附劣化晶圓表面電性或微影成形的微量氣態化學物質，分為酸、鹼、有機物及摻雜物四大類。 | [第 8 章](part-02/02-02.md) |
| **APC** | （進階製程控制）：利用 EWMA 等數學模型，在批次間（R2R）動態調整機台配方以補償變異之控制系統。 | [第 54 章](part-09/09-12.md) |
| **Availability** | （系統可用度）：系統在特定時間內維持正常運轉狀態的機率，數學上以平均故障間隔時間與平均修復時間之比值表示。 | [第 55 章](part-13/13-01.md) |

| **Band-to-Band Tunneling / BTBT** | （能帶間穿隧）：強電場作用下，重摻雜接面之價帶電子直接量子穿隧進入導帶所產生的逆向接面漏電機制。 | [第 6 章](part-01/01-06.md) |
| **BGN** | （能隙變窄效應，Bandgap Narrowing）：重度摻雜下載子間庫侖屏蔽及交換交互作用促使材料有效禁帶寬度縮小的現象。 | [第 2 章](part-01/01-02.md) |
| **Bloch's Theorem** | （布洛赫定理）：描述在週期性晶格勢場中運動的電子波函數，可表述為自由平面波與具晶格週期性函數之乘積的量子力學定理。 | [第 1 章](part-01/01-01.md) |
| **BMD** | （體微缺陷，Bulk Microdefect）：在矽晶圓深層內部由過飽和氧析出形成的二氧化矽微沉澱物及其伴生微差排，為內部吸雜的主要物理捕捉結構。 | [第 7 章](part-02/02-01.md) |
| **Body Effect** | （基板偏壓效應）：源極與基板間的電位差導致空乏區電荷增加，進而改變臨界電壓的現象。 | [第 4 章](part-01/01-04.md) |
| **Bow** | （彎曲度）：中平面中心點相對於由邊緣固定半徑三點建立之基準平面的垂直位移量，具正負幾何方向性。 | [第 8 章](part-02/02-02.md) |
| **BPS Model** | （BPS 理論模型）：由 Barton、Prime 與 Slichter 提出，考量固液界面停滯邊界層擴散限制後，計算雜質有效偏析係數 $k_{eff}$ 的動力學公式。 | [第 7 章](part-02/02-01.md) |
| **Carrier Freeze-out** | （載子凍結）：在極低溫環境下載子動能低於游離能，絕大部分載子被束縛於雜質原子能階而使自由載子濃度急遽衰減的現象。 | [第 2 章](part-01/01-02.md) |
| **Carrier Mobility** | （載子遷移率，$\mu$）：表徵微觀載子在單位外加電場加速作用下所能獲得的定向漂移速度比例常數。 | [第 2 章](part-01/01-02.md) |
| **Ceiling Plenum** | （天花板靜壓室）：無塵室吊頂上方維持加壓狀態之密閉空腔，用於均勻分配新風並加壓送入濾網單元。 | [第 55 章](part-13/13-01.md) |
| **Central Utility Building** | （中央動力廠房，CUB）：獨立於主廠房之外的集中式能源供應建物，負責生產冷卻水、蒸氣、壓縮空氣與變電配送。 | [第 55 章](part-13/13-01.md) |
| **Charge Neutrality Condition** | （電荷中性條件）：在宏觀體積尺度下，半導體內部自由載子與游離帶電離子的代數和為零之物理平衡狀態。 | [第 2 章](part-01/01-02.md) |
| **Complementary FET / CFET** | （互補型場效電晶體）：將 n 型與 p 型金氧半場效電晶體於垂直方向直接進行三維堆疊，以消除橫向井區隔離間距之新世代標準單元架構。 | [第 6 章](part-01/01-06.md) |
| **Conduction Band, CB** | （導電帶 / 導帶）：位於價電帶上方之第一個未填滿（或完全為空）的能帶，其內部電子可自由移動形成電流。 | [第 1 章](part-01/01-01.md) |
| **Continuity Equation** | （連續方程式）：基於電荷守恆定律，完整描述半導體內部載子濃度因傳輸梯度、產生率與復合率動態演變的微分方程。 | [第 2 章](part-01/01-02.md) |
| **COP** | （晶穴缺陷，Crystal-Originated Particles）：晶體冷卻過程中過飽和空位聚集形成之微觀八面體空洞，經清洗微蝕刻後於表面暴露形成的奈米級凹坑。 | [第 7 章](part-02/02-01.md) |
| **Crystal Momentum** | （晶體動量）：由約化普朗克常數與波向量乘積（$\mathbf{p}_{\text{crystal}} = \hbar \mathbf{k}$）定義之有效動量，在週期性勢場交互作用下遵循守恆律。 | [第 1 章](part-01/01-01.md) |
| **Cunningham Slip Correction Factor** | （肯寧漢滑移修正係數）：當微粒粒徑接近空氣分子平均自由徑時，用以修正微粒表面流體滑移效應對斯托克斯阻力減小之經驗係數。 | [第 55 章](part-13/13-01.md) |
| **CZ Method** | （柴氏長晶法，Czochralski Method）：將電子級多晶矽於石英坩堝內熔解，藉由浸入種晶並精確控制提拉與旋轉，拉製成單晶矽錠的生長工藝。 | [第 7 章](part-02/02-01.md) |
| **Dash Necking** | （縮頸技術）：在種晶浸入高溫熔液後以高拉速生長細頸結構，利用晶格幾何邊界迫使熱震引發的滑移差排滑出晶體自由表面以消除線缺陷的關鍵工藝。 | [第 7 章](part-02/02-01.md) |
| **Degenerate Semiconductor** | （簡併半導體）：摻雜濃度極高以致費米能階進入導帶或價帶內部，導致波茲曼近似失效且展現類金屬特徵的半導體。 | [第 2 章](part-01/01-02.md) |
| **Density of States, DOS** | （狀態密度）：單位能量區間與單位晶體體積內，允許電子佔據的微觀量子態數量。 | [第 1 章](part-01/01-01.md) |
| **Denuded Zone** | （表面無缺陷區，DZ）：經由高溫氧外擴散退火後，在晶圓表層所形成氧濃度極低、無氧化沉澱物與微缺陷的主動元件製作區域。 | [第 7 章](part-02/02-01.md) |
| **Diamond Structure** | （鑽石結構）：由兩個面心立方（FCC）晶格沿對角線位移四分之一晶胞長度相互套構而成的晶體結構，為矽與鍺的標準晶體型態。 | [第 1 章](part-01/01-01.md) |
| **Diffusion Current** | （擴散電流）：載子純因濃度空間分佈不均，透過微觀隨機熱運動產生巨觀淨定向流動所形成的電流。 | [第 2 章](part-01/01-02.md) |
| **Direct Bandgap** | （直接能隙）：導電帶能量最低點與價電帶能量最高點座落於第一布里淵區相同波向量（通常在 $\Gamma$ 點）的能帶結構。 | [第 1 章](part-01/01-01.md) |
| **Donor** | （施體）：具有 5 個價電子之週期表第 V 族元素雜質，游離後提供自由導電電子並在晶格中留下帶正電的固定離子。 | [第 2 章](part-01/01-02.md) |
| **DOS** | （能態密度，Density of States）：單位體積內、單位能量區間所允許存在的電子或量子態數目。 | [第 2 章](part-01/01-02.md) |

| **DSL** | （雙面研磨）：使用游離磨料懸浮液在上下研磨盤旋轉滾動摩擦下，均勻切削晶圓兩面以降低巨觀厚度變異的工藝。 | [第 8 章](part-02/02-02.md) |
| **DSP** | （雙面拋光）：晶圓於遊星輪夾持下同步對正反兩面施加化學拋光，能兼顧優良全域平坦度並消除夾持彎曲變形的鏡面化加工架構。 | [第 8 章](part-02/02-02.md) |
| **DWS** | （金剛石線鋸）：以高強度金屬線為芯線、表面固著微米級金剛石磨粒的高速切片技術，藉脆性微刮擦機制分割晶棒。 | [第 8 章](part-02/02-02.md) |
| **EAP** | （設備自動化程式）：介於 MES 與實體機台間的中介軟體，負責指令轉譯、配方下載與自動化邏輯交握。 | [第 54 章](part-09/09-12.md) |
| **Edge Profiling** | （邊緣倒角）：利用成形砂輪將切片後晶圓直角邊緣研磨成圓弧狀或多面斜角，以消除應力集中並抑制邊緣碎裂與微塵掉落之製程。 | [第 8 章](part-02/02-02.md) |
| **EEZ** | （邊緣排除區）：晶圓物理外徑向內算起的邊界環狀禁區，此區域因設備夾持與邊緣效應嚴重而不列入元件良率與幾何規格規範。 | [第 8 章](part-02/02-02.md) |

| **空乏電容（Depletion Capacitance, $C_j$）** | ：由外加逆偏電壓改變所引起之空間電荷區邊界固定離子電荷伸縮之等效平板電容。 | [第 3 章](part-01/01-03.md) |
| **空間電荷區（Space Charge Region, SCR）** | ：接面兩側因自由載子擴散抽離後，留下無法移動的游離施體與受體離子所構成的高阻抗強電場區域，又稱空乏區。 | [第 3 章](part-01/01-03.md) |
| **突崩崩潰（Avalanche Breakdown）** | ：高電場空乏區內載子藉由連鎖碰撞游離反應導致逆向電流急遽倍增之物理現象，具備正溫度係數。 | [第 3 章](part-01/01-03.md) |
| **等電場微縮（Constant-Electric-Field Scaling, CEF）** | ：登納德提出之元件微縮法則，要求幾何尺寸與工作電壓以相同比例調降，以維持元件內部電場強度與功耗密度為定值。 | [第 5 章](part-01/01-05.md) |
| **等電壓微縮（Constant-Voltage Scaling, CV）** | ：僅微縮幾何尺寸而固定電源電壓不變的微縮方式，會導致內部電場急遽增強並使功耗密度呈三次方形勢爆炸。 | [第 5 章](part-01/01-05.md) |
| **臨界電場（Critical Electric Field, $\mathcal{E}_{crit}$）** | ：半導體材料抵抗介質擊穿之最大極限電場，達到此值將引發大規模逆向崩潰。 | [第 3 章](part-01/01-03.md) |
| **臨界電壓滾降（$V_{\text{th}}$ Roll-off）** | ：在短通道元件中，臨界電壓隨閘極長度縮減而單調下跌的現象，主要由邊界電荷共享所引起。 | [第 5 章](part-01/01-05.md) |
| **蕭克利理想二極體方程式（Shockley Diode Equation）** | ：描述少數載子擴散傳輸主導下，理想接面電流隨外加電壓呈指數成長之經典解析式。 | [第 3 章](part-01/01-03.md) |
| **蕭基能障（Schottky Barrier, $\Phi_{B}$）** | ：金屬與半導體接觸達到熱平衡時，介面處因功函數差異阻礙載子傳輸之位能障壁。 | [第 3 章](part-01/01-03.md) |
| **費米能階釘選（Fermi-level Pinning）** | ：金屬-半導體交界面處高密度表面態電離形成偶極層，使介面費米能階錨定於中性能階而降低對金屬功函數相依性之現象。 | [第 3 章](part-01/01-03.md) |
| **超淺接面（Ultra-Shallow Junction, USJ）** | ：將源汲極延伸區深度壓縮至數十奈米以下的製程技術，用以減小汲極橫向靜電耦合截面積並抑制短通道效應。 | [第 5 章](part-01/01-05.md) |
| **逆向恢復時間（Reverse Recovery Time, $t_{rr}$）** | ：PN 二極體由順向導通狀態突切為逆向截止狀態時，清除儲存少數載子並重建空乏區阻斷能力所需的暫態時間。 | [第 3 章](part-01/01-03.md) |
| **逆行井（Retrograde Well）** | ：表面摻雜較低而在次表面深處具有高雜質濃度峰值的井區結構，用以抑制次表面空乏區橫向擴展並防止打穿。 | [第 5 章](part-01/01-05.md) |
| **電荷共享模型（Charge-Sharing Model）** | ：由 Yau 提出的一階幾何靜電分析模型，解釋源極與汲極接面內建電位分擔了部分通道空乏電荷，造成閘極所需反轉電荷與臨界電壓降低。 | [第 5 章](part-01/01-05.md) |
| **齊納崩潰（Zener Breakdown）** | ：重摻雜極窄接面受逆向偏壓時，由帶對帶量子穿隧機制主導之非破壞性崩潰現象，具備負溫度係數。 | [第 3 章](part-01/01-03.md) |
